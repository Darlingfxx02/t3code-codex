## Architecture criteria

- Additive module and route: **partially met**. Task domain is isolated, but the shared dirty checkout contains unrelated work.
- Typed contracts and RPC/auth: **met for the declared surface**. `taskWorkspace.read` and `taskWorkspace.command` are typed and authorization/instrumentation entries exist.
- Ownership and concurrency: **partially met**. RPC derives both the server environment and project root, task-state locks are shared by state-file key, concurrent dispatch receipts use a dedicated per-state write semaphore, and configured Jira sources persist into deterministic source-specific snapshots behind a pointer file. A full migration away from the legacy pointer path is still pending.
- Local-first boundary: **partially met**. Jira sync is read-only; draft and task state are local. Push/comment workflow is wired with explicit receipt phases and recorded remote URL, but no live external mutation was exercised.
- Evidence and runners: **partially met**. Queued-before-dispatch durability, source SHA, same-repository worktree validation, agent/audit/check outputs, real configured check exit codes, retries, cancellation, source-specific state, detached auto-sync watcher and preflight/readiness-checked managed Storybook launch are wired; no live Storybook/publish action was exercised.
- Council: **completed, below target**. Round 1: Claude Opus design 4/10, GPT Sol technical 3/10. Round 2 after fixes: Claude Opus design 5/10, GPT Sol technical 4.5/10. Latest independent reviews of the evolving tree: design 7.0/10 and technical 8.9/10; these are not a 9+ approval for this exact checkout because browser access is currently unavailable. Remaining evidence gaps are live runtime execution, provider/worktree waves, managed Storybook process launch, Storybook/publish mutation, restart proof, and native mobile coverage.
